This patch release clears the last finding of Obsidian's community plugin scanner for 0.7.4. The plugin now requires Obsidian 1.13, which the settings pages introduced in 0.7.4 are built on, and its lint runs the same rules the scanner reports from.

## ⚠️ Compatibility

- **Minimum Obsidian version is now 1.13.0** (was 1.7.2) ([#102](https://github.com/akhmialeuski/obsidian-citation-extended/pull/102)). The settings tab is drawn as section pages with Obsidian's `SettingPage`, which exists from 1.13. The scanner reported that use against the old minimum, and the one-page tab kept for older versions called `display()`, which 1.13 deprecates. That tab is removed. Obsidian picks 0.7.4 for a vault on an older version, so nothing breaks there.

## 🔧 Under the Hood

- **The lint runs the scanner's rules** ([#102](https://github.com/akhmialeuski/obsidian-citation-extended/pull/102)). `npm run lint` now builds on the recommended config of `eslint-plugin-obsidianmd`, which the community plugin scanner uses, instead of a hand-picked list of its rules, and fails on any warning. A finding the scanner would report now stops the commit.
- The configuration guide drops the two screenshots of the one-page settings tab.
- The test suite has 1,881 tests across 101 suites, all passing.
