This patch release clears the findings of Obsidian's community plugin scanner. It upgrades three dependencies past their security advisories, shows the settings as section pages on Obsidian 1.13 and later, and states in the README which files the plugin reads and what it writes to the clipboard.

## ✨ New Features

- **Settings as section pages on Obsidian 1.13** ([#101](https://github.com/akhmialeuski/obsidian-citation-extended/pull/101)). On Obsidian 1.13 and later, **Settings** > **Citation Extended** lists five pages: **Citation databases**, **Literature notes**, **Fragment profiles**, **Markdown citation templates** and **Display**, each with the same settings as before. The settings search finds a page by its name, not a single setting inside it. Older versions of Obsidian keep every section on one page.

## 🔒 Security

- **Dependencies past their advisories** ([#101](https://github.com/akhmialeuski/obsidian-citation-extended/pull/101)). `handlebars` moves to 4.7.10, which fixes two critical template injection advisories, `zod` to 4.6.7, since no 3.x release fixes GHSA-mrhx-c7xc-m3w5, and `picomatch` to 2.3.2 and 4.0.7. The settings schema needed one change for `zod` 4, and its tests pass unchanged.

## 📚 Documentation

- **File and clipboard access** ([#101](https://github.com/akhmialeuski/obsidian-citation-extended/pull/101)). A new README section, next to Network Use, lists what the plugin reads outside the vault (the library file of a file database), how it finds literature notes in the vault, what **Tab** and **Shift+Tab** open from **Open literature note**, and that it only writes to the clipboard, from **Copy bibliography** and **Copy all**.
- The configuration guide shows the settings pages of Obsidian 1.13.

## 🔧 Under the Hood

- **Styles moved into the stylesheet** ([#101](https://github.com/akhmialeuski/obsidian-citation-extended/pull/101)). The database cards, number inputs, status lines, field errors and the template variable list take their look from classes in `styles.css` instead of inline styles, so a theme can restyle them.
- **The scanner's source review runs through.** The ESLint bulk suppressions moved from `eslint-suppressions.json` to `.eslint/suppressions.json`, because the scanner's ESLint read the root file, found its entries unused and stopped with a fatal error.
- The test suite has 1,882 tests across 101 suites, all passing.
